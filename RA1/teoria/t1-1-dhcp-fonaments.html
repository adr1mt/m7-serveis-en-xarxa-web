IP manual o configuració per DHCP?

Hi ha dues maneres de configurar un equip: escriure les dades manualment o demanar-les a un servidor DHCP.

Rebre la configuració per DHCP no vol dir que la IP canviï sempre. Amb una reserva, el servidor dona la mateixa IP a aquell equip. El client continua fent servir DHCP.

En el nostre laboratori, el servidor DHCP té una IP manual a la targeta interna; els clients li demanen la configuració.

El problema que resol DHCP

Perquè un equip funcioni en xarxa necessita quatre dades: IP, màscara, porta d'enllaç i DNS. Posar-les a mà va bé amb tres màquines. Amb tres-centes, no.

Configurar a mà una xarxa gran té tres problemes:

  • Cal apuntar quina IP té cada equip per no repetir-ne cap.
  • Si un portàtil canvia d'aula, s'ha de reconfigurar.
  • Canviar el DNS del centre vol dir tocar totes les màquines.

DHCP (Dynamic Host Configuration Protocol) posa aquesta feina en un servidor. Tu defineixes la configuració una sola vegada i cada equip que es connecta la demana i la rep sol. És el que fa el router de casa teva i el Wi-Fi de l'institut: canvia la mida, no el mecanisme.

Funcionament: el procés DORA

Hi ha una pregunta òbvia: si el client encara no té IP, com pot demanar res? Ho fa per difusió (broadcast), un missatge que arriba a tothom del segment. DHCP treballa sobre UDP: el servidor escolta al port 67 i el client al 68.

01
DISCOVER
El client crida: «hi ha algun servidor DHCP?»
→
02
OFFER
El servidor ofereix una IP del seu rang.
→
03
REQUEST
El client accepta aquella oferta.
→
04
ACK
El servidor confirma. Ja pots fer servir l'adreça.

Si responen diversos servidors, el client tria una oferta i la demana amb REQUEST. L’ACK confirma la concessió (lease): el dret a fer servir aquella IP durant un temps limitat.

L’adreça es presta, no es regala. Habitualment, a la meitat del temps el client demana renovar-la amb REQUEST i el servidor respon ACK. Si no la pot renovar i caduca, ha de deixar de fer servir la IP.

Tres maneres d’assignar adreces

La diferència principal és qui configura l’equip. Si fa servir DHCP, el servidor pot triar una IP lliure o donar-li la que té reservada.

ConfiguracióCom rep la IP?Exemple
Manual (estàtica)L’escrius a l’equip. No demana la IP per DHCP.Targeta interna del servidor DHCP
DHCP sense reservaEl servidor tria una IP lliure del rang dinàmic (pool).Portàtil d’un alumne
DHCP amb reservaEl servidor associa un identificador de l’equip, com la MAC, a una IP concreta.Impressora amb una IP estable

Una reserva no és una IP escrita manualment al client. La IP és estable, però la configuració arriba per DHCP, amb la seva concessió. A més de la IP, el servidor pot enviar màscara, porta d’enllaç i DNS.

Un DHCP que no toca

Un router domèstic connectat a l’aula pot respondre peticions DHCP i donar una porta d’enllaç incorrecta. És un DHCP furtiu: un servidor no autoritzat que interfereix amb la configuració de la xarxa.

Al laboratori, el nostre DHCP només ha de donar servei a personal1, mai a la xarxa del centre puigcastellar1.

Si un equip s’assigna una IP 169.254.x.x, és una adreça d’enllaç local: no és una concessió del nostre DHCP ni li dona sortida a Internet.

Resum

  • DHCP envia IP, màscara, porta d’enllaç i DNS al client.
  • Fa servir UDP: port 67 al servidor i 68 al client.
  • DORA: Discover → Offer → Request → ACK.
  • La concessió limita el temps d’ús de la IP; es pot renovar.
  • IP manual, o configuració per DHCP amb reserva o sense.
