Servidor DHCP mínim amb systemd-networkd

Muntar un DHCP de laboratori sense instal·lar absolutament res.

Amb què treballaràs

MàquinaTargetaPaper
Ubuntu Serverpuigcastellar1 + personal1Servidor DHCP, IP fixa 10.0.0.1/8
Ubuntu Desktoppersonal1Client, ha de rebre la configuració

Reaprofita el servidor preparat a A1.1. Abans de començar, comprova les dues targetes, la configuració de Netplan i que encara no hi hagi cap servidor DHCP actiu. En aquesta activitat canviaràs la gestió de xarxa i la IP interna a 10.0.0.1/8. El client ha de demanar la configuració per DHCP. Treballa al servidor per SSH des de l’amfitrió.

Què has de fer

Consulta la G1.1 per entendre la relació entre Netplan i networkd; per al servidor integrat, la guia G1.4.

  1. Aparta la configuració de Netplan perquè no competeixi amb els fitxers de networkd.
  2. Configura les targetes amb systemd-networkd: externa per DHCP i interna personal1 amb 10.0.0.1/8. Comprova els noms reals abans d’escriure els fitxers.
  3. Activa el DHCP integrat només a personal1: 20 adreces a partir de 10.0.0.100 i DNS 9.9.9.9. El rang es defineix amb un desplaçament i una mida.
  4. Comprova que el client rep una IP del rang i el DNS, i arriba al servidor. Encara no ha de tenir Internet: no has configurat encaminament ni NAT.
  5. Captura una negociació inicial i identifica els quatre missatges DORA. Una renovació amb només Request/ACK no demostra la seqüència completa.

Què has d’entregar

Entrega un document breu amb la configuració i aquestes evidències:

  • Netplan apartat, fitxers de networkd, IP interna i servei escoltant a UDP 67.
  • IP i DNS rebuts pel client, i connectivitat amb el servidor.
  • Captura amb Discover, Offer, Request i ACK identificats.

Explica per què has apartat Netplan. Al Desktop, comprova quin gestor de xarxa utilitza el client abans de triar l’eina de renovació.
