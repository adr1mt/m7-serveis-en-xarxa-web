Què hi ha en aquesta guia

Documentació oficial: projecte xrdp, manual de xrdp.ini i notes d'Ubuntu 26.04 LTS.

  • Punt de partida: una màquina nova Ubuntu Desktop 26.04 d'isardVDI.
  • xrdp necessita una sessió X.org. GNOME d'Ubuntu 26.04 només funciona amb Wayland; per això instal·larem XFCE per a les sessions remotes.

Instal·lar i comprovar

  1. Instal·la el servei, el connector X.org i XFCE:

    Terminal
    sudo apt update
sudo apt install -y xrdp xorgxrdp xfce4

  2. Indica l'escriptori de la sessió remota:

    Terminal
    printf 'exec startxfce4\n' > ~/.xsession

  3. Dona a xrdp accés a la clau TLS i obliga'l a usar TLS:

    Terminal
    sudo adduser xrdp ssl-cert
sudo sed -i 's/^security_layer=.*/security_layer=tls/' /etc/xrdp/xrdp.ini
sudo systemctl restart xrdp-sesman xrdp

  4. Comprova els serveis, el certificat i el port:

    Terminal
    systemctl is-active xrdp
systemctl is-active xrdp-sesman
sudo -u xrdp sh -c 'test -r /etc/xrdp/cert.pem && test -r /etc/xrdp/key.pem'
grep '^security_layer=' /etc/xrdp/xrdp.ini
sudo ss -lntp | grep :3389

    Les quatre comprovacions han d'acabar sense error i la configuració ha de mostrar security_layer=tls.

Connectar-se des del client

  1. Des de Linux, amb Remmina: protocol RDP, la IP del servidor (ip -brief a) i les credencials de l'usuari del sistema.

  2. Des de Windows, amb «Conexión a Escritorio remoto»: mateixa IP i credencials.

Una sessió gràfica per connexió

xrdp obre una sessió XFCE pròpia; no comparteix la sessió GNOME/Wayland que pugui haver-hi oberta a la consola local. Fes la prova remota amb un usuari que no tingui una altra sessió gràfica oberta.

Comprovar-ho de conjunt

  1. El client de RDP mostra l'escriptori XFCE, amb la mateixa resolució o similar a la finestra del client.

  2. Es pot obrir un terminal dins de la sessió gràfica i navegar pel sistema de fitxers amb normalitat.

Bones pràctiques

  • RDP mai directe a Internet: sempre darrere d'una VPN o d'un túnel SSH (G6.1).
  • Força security_layer=tls. La versió 0.10.1 provada a Ubuntu 26.04 és anterior a la correcció 0.10.6; l'avís oficial d'xrdp indica TLS com a mitigació del problema de la capa RDP clàssica.
  • El xifrat de RDP no substitueix cap altra mesura de seguretat: usuaris i contrasenyes robustes continuen sent imprescindibles.
  • Tanca la sessió gràfica en acabar, no la deixis oberta indefinidament.

Problemes

Pantalla en negre en entrar

Causa S'ha intentat iniciar GNOME, que a Ubuntu 26.04 només funciona amb Wayland, o l'usuari ja té una altra sessió gràfica.

Solució Comprova que ~/.xsession conté exec startxfce4 i tanca les altres sessions de l'usuari.

El client diu que la sessió ja està en ús

Causa xrdp no permet compartir la mateixa sessió gràfica entre la consola local i una connexió remota.

Solució Desconnecta l'altra sessió o entra amb un altre compte.

El client no arriba a connectar

Causa El tallafoc de la màquina bloqueja el port 3389.

Solució Obre el port amb nftables i torna-ho a provar.
