Un web sense nom no és un web

Els hosts virtuals trien el lloc pel nom que demana el navegador, i aquest nom l'ha de resoldre algú. Al laboratori n'hi ha prou amb el fitxer hosts del client, però la manera bona és publicar-lo a una zona pròpia, com vas fer al RA2.
